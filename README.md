# UMA NOITE DE CRIME — s y r i u s.

Apresentação interativa em slides do álbum **UMA NOITE DE CRIME**, do artista **s y r i u s.**, feita como um plano de lançamento e marketing.

> Obra de ficção. Personagens, eventos e enredos são fictícios e criados para fins artísticos.

## Sobre o projeto

Um site de uma única página que funciona como uma apresentação de slides: o álbum é uma noite inteira, das 22h às 6h, e cada faixa é uma hora dessa noite. A paleta vai do preto ao roxo, com tipografia moderna e animações leves.

## Slides

1. Capa
2. Conceito
3. O artista
4. Tracklist interativa (12 faixas)
5. Identidade sonora
6. Público
7. Plano de lançamento em 4 atos
8. Ações de campanha
9. Metas
10. Encerramento

## Como usar

Abra o arquivo `index.html` no navegador. Não há dependências nem etapa de build.

**Navegação**

| Ação | Como fazer |
| --- | --- |
| Avançar / voltar | Setas do teclado, espaço, scroll do mouse ou swipe no celular |
| Ir para um slide | Clique nos pontos na parte de baixo |
| Tela cheia | Tecla `F` |

## Tecnologias

- HTML, CSS e JavaScript puros (um único arquivo)
- Fontes do Google Fonts: Unbounded, Instrument Serif, Bricolage Grotesque e JetBrains Mono

## Publicação

O site pode ser publicado de graça com o GitHub Pages: **Settings → Pages → Branch `main` → `/ (root)`**.
